# 常见操作

下面是 Vim 的常见操作和命令，涵盖了**模式切换、文件操作、移动光标、文本编辑、复制粘贴、搜索替换等核心功能**，非常适合日常使用和入门学习：

---

## 🧠 Vim 的三种主要模式

| 模式名称            | 功能                   | 进入方式                                               |
| ------------------- | ---------------------- | ------------------------------------------------------ |
| 普通模式（Normal）  | 移动光标、删除、复制等 | 启动 Vim 后默认就是普通模式；或从其他模式按 `Esc` 返回 |
| 插入模式（Insert）  | 输入/编辑文本          | `i`、`a`、`o` 等                                       |
| 命令模式（Command） | 保存、退出、搜索等     | 在普通模式下按 `:`                                     |

---

## 📝 插入模式（输入文字）

| 命令  | 说明                     |
| ----- | ------------------------ |
| `i`   | 在光标前插入             |
| `a`   | 在光标后插入             |
| `o`   | 在下一行插入新行         |
| `I`   | 在当前行行首插入         |
| `A`   | 在当前行行尾插入         |
| `Esc` | 退出插入模式回到普通模式 |

---

## 🔍 光标移动

| 命令                | 说明                         |
| ------------------- | ---------------------------- |
| `h` / `l`           | 左 / 右                      |
| `j` / `k`           | 下 / 上                      |
| `w` / `b`           | 跳到下一个/上一个单词开头    |
| `0` / `^` / `$`     | 行首 / 第一个非空字符 / 行尾 |
| `gg` / `G`          | 文件开头 / 结尾              |
| `:n`                | 跳转到第 `n` 行              |
| `Ctrl-d` / `Ctrl-u` | 向下 / 向上翻半页            |
| `Ctrl-f` / `Ctrl-b` | 向下 / 向上翻一页            |

---

## ✂️ 删除操作（在普通模式）

| 命令     | 说明                 |
| -------- | -------------------- |
| `x`      | 删除当前字符         |
| `dd`     | 删除当前行           |
| `dw`     | 删除一个单词         |
| `d$`     | 删除光标到行尾       |
| `d0`     | 删除光标到行首       |
| `dG`     | 删除当前行到文件结尾 |
| `u`      | 撤销上一步操作       |
| `Ctrl-r` | 恢复撤销的操作       |

---

## 📋 复制粘贴（在普通模式）

| 命令  | 说明                |
| ----- | ------------------- |
| `yy`  | 复制当前行          |
| `y3j` | 复制当前行起下 3 行 |
| `p`   | 粘贴到光标后        |
| `P`   | 粘贴到光标前        |

---

## 🔍 搜索与替换

| 命令           | 说明                     |
| -------------- | ------------------------ |
| `/关键词`      | 向下搜索关键词           |
| `?关键词`      | 向上搜索关键词           |
| `n` / `N`      | 下一个 / 上一个匹配项    |
| `:%s/旧/新/g`  | 全文替换所有“旧”为“新”   |
| `:s/旧/新/g`   | 替换当前行所有“旧”为“新” |
| `:%s/旧/新/gc` | 全文逐个确认替换         |

---

## 💾 文件保存与退出（命令模式，先按 `:`）

| 命令          | 说明           |
| ------------- | -------------- |
| `:w`          | 保存           |
| `:q`          | 退出           |
| `:wq` 或 `ZZ` | 保存并退出     |
| `:q!`         | 强制退出不保存 |
| `:e 文件名`   | 打开文件       |
| `:w 文件名`   | 另存为         |

---

## 📐 可视模式（选择文本）

| 命令      | 说明                  |
| --------- | --------------------- |
| `v`       | 字符选择模式          |
| `V`       | 行选择模式            |
| `Ctrl-v`  | 块选择（列选择）模式  |
| `y` / `d` | 复制 / 删除选中的区域 |

---

## 🔧 其他有用命令

| 命令                 | 说明                   |
| -------------------- | ---------------------- |
| `.`                  | 重复上一次操作         |
| `:%!xxd`             | 查看文件的十六进制格式 |
| `:set nu`            | 显示行号               |
| `:set nonu`          | 取消行号               |
| `:syntax on`         | 语法高亮               |
| `:split filename`    | 水平分屏打开文件       |
| `:vsplit filename`   | 垂直分屏打开文件       |
| `Ctrl-w` + `h/j/k/l` | 切换分屏窗口           |

---
