# 常见命令

Linux 常见命令可以分为以下几大类：**文件操作、目录管理、权限管理、系统监控、网络操作、进程管理、包管理、用户管理等**。下面是最常用的命令清单，适合日常开发、部署和运维使用。

---

## 📁 一、文件与目录操作

| 命令            | 说明                                                           |
| --------------- | -------------------------------------------------------------- |
| `ls`            | 查看当前目录文件（`ls -l` 查看详细信息，`ls -a` 查看隐藏文件） |
| `cd`            | 切换目录，如 `cd /home/user`                                   |
| `pwd`           | 显示当前路径                                                   |
| `mkdir`         | 创建目录，如 `mkdir new_folder`                                |
| `rm`            | 删除文件/目录（`rm -r` 删除目录，`rm -rf` 强制删除）           |
| `cp`            | 复制文件/目录（`cp -r` 复制目录）                              |
| `mv`            | 移动或重命名文件/目录                                          |
| `touch`         | 创建空文件                                                     |
| `cat`           | 查看文件内容                                                   |
| `more` / `less` | 分页查看大文件                                                 |
| `head` / `tail` | 查看文件开头/结尾，`tail -f` 实时查看日志                      |
| `tree`          | 显示目录结构（可能需要安装）                                   |

# shell 和 linux

这是一个非常常见但容易混淆的问题。我们来**一针见血**地说清楚：

---

## ✅ 简单结论：

> **Linux 命令 是系统中可用的命令，Shell 命令 是运行在 Shell 解释器中的命令。**
>
> ✔ 所有 Shell 命令 ≈ 都在 Shell 中执行
> ✔ 部分 Linux 命令 是外部程序，Shell 用来调用它们

---

## 🧠 一句话理解：

> **Shell 是“外壳”，Linux 命令是你发给这个外壳的“指令”。**

---

## 🔍 更具体地讲：

### 1. 什么是 Shell？

- Shell 是一种命令行解释器，是用户与操作系统之间的“桥梁”。
- 最常见的 Shell 是 **Bash**（Bourne Again Shell）。
- Shell 也可以写脚本，如 `.sh` 文件。

**Shell 提供了：**

- 命令解析
- 流程控制（`if`, `for`, `while`）
- 变量（`a=123`）
- 重定向（`>`、`|`）
- 内置命令（如 `cd`, `echo`, `alias`, `export`）

---

### 2. 什么是 Linux 命令？

Linux 命令一般是：

- **Shell 的内建命令**（如：`cd`, `echo`, `alias`）
- **Linux 系统自带的可执行程序**（如：`ls`, `cp`, `mkdir`, `ps`, `netstat`）
- **第三方安装的可执行程序**（如：`node`, `docker`, `git`）

这些命令大多数是存放在 `/bin`, `/usr/bin`, `/sbin` 等目录下的 **二进制程序或脚本**。

---

## 🧪 举个例子：输入一个命令 `ls -l`

```bash
ls -l
```

实际过程是：

1. Shell 接收到命令 `ls -l`
2. 去 PATH 路径下找 `ls` 这个可执行程序（通常在 `/bin/ls`）
3. 调用它，参数是 `-l`
4. 把输出结果显示在终端上

---

## 🔧 示例对比：Shell 内置命令 vs Linux 命令

| 命令           | 类型                 | 说明                       |
| -------------- | -------------------- | -------------------------- |
| `cd`           | Shell 内建           | 改变当前目录，不是独立程序 |
| `echo`         | Shell 内建           | 打印输出                   |
| `pwd`          | 既是内建也有外部版本 | 打印当前路径               |
| `ls`           | 外部命令             | 是 `/bin/ls` 可执行程序    |
| `ps`           | 外部命令             | 查看进程（`/bin/ps`）      |
| `if/for/while` | Shell 语法           | Shell 控制结构，不是命令   |
| `which`        | 外部命令             | 查找命令路径               |

---

## 💡 如何判断命令是 Shell 内建的，还是 Linux 外部命令？

用 `type` 命令判断：

```bash
type cd       # cd is a shell builtin
type ls       # ls is /bin/ls
type echo     # echo is a shell builtin
```

---

## 🏁 总结对比表

| 对比维度       | Shell 命令                   | Linux 命令（外部命令）            |
| -------------- | ---------------------------- | --------------------------------- |
| 执行位置       | Shell 解释器内               | 系统文件路径（如 `/bin/ls`）      |
| 是否可编程     | 是，支持变量、流程控制       | 否，除非你自己写脚本包装          |
| 是否可单独运行 | 否，依赖 Shell               | 是，可以脱离 Shell 被其他程序调用 |
| 举例           | `cd`, `echo`, `export`, `if` | `ls`, `cp`, `rm`, `ps`, `grep`    |

## 📌 推荐用法技巧

- `set -e`: 脚本遇错立即退出
- `set -x`: 打印执行的每一条命令（调试用）
- `$(command)`: 执行命令并取结果，例如 `filename=$(date +%F)`
