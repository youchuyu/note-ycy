# react-i18next

非常好 👍
我们来**详细系统地介绍一下 `react-i18next`** —— 它是 React 生态中最强大、使用最广泛的国际化（i18n）解决方案之一。
下面我会从原理 → 安装 → 使用 → 配置 → 进阶技巧 → 最佳实践 全面讲解。

---

## 🧩 一、react-i18next 是什么？

`react-i18next` 是基于国际化核心库 **i18next** 的 React 封装。

- ✅ **核心库 i18next**：提供国际化核心能力（如多语言存储、切换、变量插值等）
- ✅ **react-i18next**：在 React 中无缝集成（支持 Hooks、Suspense、SSR、动态加载等）

> 📖 官网文档: [https://react.i18next.com](https://react.i18next.com)

---

## ⚙️ 二、核心特性概览

| 特性                       | 说明                                         |
| -------------------------- | -------------------------------------------- |
| 🧠 **Hooks 支持**          | `useTranslation()` 获取翻译函数 `t()`        |
| 🔄 **动态切换语言**        | `i18n.changeLanguage('en')`                  |
| 📦 **多命名空间**          | 每个模块独立语言包                           |
| ⏳ **按需懒加载**          | 使用 `i18next-http-backend` 从服务器加载语言 |
| 🌐 **浏览器语言检测**      | 自动检测用户语言                             |
| 💬 **变量插值 & 复数处理** | 支持 `{{name}}` 和 plural 规则               |
| ⚡ **React Suspense 支持** | 可在语言加载时显示 loading                   |
| 🔁 **SSR 支持**            | Next.js / Remix 等框架完美集成               |

## 🪄 四、快速上手实例

### 1️⃣ 目录结构建议

```
src/
 ├─ i18n/
 │   ├─ index.ts
 │   ├─ locales/
 │   │   ├─ en/translation.json
 │   │   └─ zh/translation.json
 ├─ components/
 │   └─ Home.tsx
 └─ main.tsx
```

---

### 2️⃣ 编写语言包

**src/i18n/locales/en/translation.json**

```json
{
  "welcome": "Welcome to our app!",
  "user": {
    "hello": "Hello, {{name}}!"
  }
}
```

**src/i18n/locales/zh/translation.json**

```json
{
  "welcome": "欢迎使用我们的应用！",
  "user": {
    "hello": "你好，{{name}}！"
  }
}
```

---

### 3️⃣ 初始化配置（`src/i18n/index.ts`）

```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import en from "./locales/en/translation.json";
import zh from "./locales/zh/translation.json";

i18n
  .use(initReactI18next) // 让 React 能访问 i18n
  .init({
    resources: {
      en: { translation: en },
      zh: { translation: zh },
    },
    lng: "zh", // 默认语言
    fallbackLng: "en", // 回退语言
    interpolation: {
      escapeValue: false, // React 已经自动防止 XSS
    },
  });

export default i18n;
```

---

### 4️⃣ 在入口文件中引入

```tsx
import ReactDOM from "react-dom/client";
import App from "./App";
import "./i18n"; // 必须引入一次初始化

ReactDOM.createRoot(document.getElementById("root")!).render(<App />);
```

---

### 5️⃣ 在组件中使用

```tsx
import { useTranslation } from "react-i18next";

export default function Home() {
  const { t, i18n } = useTranslation();

  return (
    <div>
      <h2>{t("welcome")}</h2>
      <p>{t("user.hello", { name: "Tom" })}</p>

      <button onClick={() => i18n.changeLanguage("en")}>English</button>
      <button onClick={() => i18n.changeLanguage("zh")}>中文</button>
    </div>
  );
}
```

## 🧠 五、常见功能详解

### 1️⃣ 变量插值（Interpolation）

```json
{ "greeting": "Hello, {{user}}!" }
```

```tsx
t("greeting", { user: "Tom" });
```

→ 输出：`Hello, Tom!`

---

### 2️⃣ 复数（Pluralization）

```json
{
  "photo": "You have {{count}} photo",
  "photo_plural": "You have {{count}} photos"
}
```

```tsx
t("photo", { count: 1 }); // => You have 1 photo
t("photo", { count: 5 }); // => You have 5 photos
```

---

### 3️⃣ 嵌套翻译（Nesting）

```json
{
  "app": {
    "title": "My App",
    "welcome": "Welcome to {{app.title}}"
  }
}
```

```tsx
t("app.welcome");
```

→ `Welcome to My App`

---

### 4️⃣ 命名空间（Namespace）

多个模块使用独立语言文件：

```
src/i18n/locales/en/
 ├─ common.json
 ├─ home.json
 └─ profile.json
```

初始化：

```ts
resources: {
  en: { common, home, profile },
  zh: { common, home, profile },
}
```

使用：

```tsx
const { t } = useTranslation("home");
t("title");
```

---

### 5️⃣ 动态加载语言包（懒加载）

安装插件：

```bash
npm install i18next-http-backend
```

修改配置：

```ts
import Backend from "i18next-http-backend";

i18n
  .use(Backend)
  .use(initReactI18next)
  .init({
    backend: {
      loadPath: "/locales/{{lng}}/{{ns}}.json",
    },
    lng: "zh",
    fallbackLng: "en",
  });
```

> 💡 此时语言包可从服务器动态获取，避免首屏体积过大。

---

### 6️⃣ 浏览器语言检测

安装：

```bash
npm install i18next-browser-languagedetector
```

配置：

```ts
import LanguageDetector from "i18next-browser-languagedetector";

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    detection: {
      order: ["localStorage", "navigator"],
    },
  });
```

## ⚡ 六、性能优化与最佳实践

| 目标                          | 建议                                                             |
| ----------------------------- | ---------------------------------------------------------------- |
| ⚡ **减少 bundle 体积**       | 启用懒加载语言包                                                 |
| 🌍 **动态切换语言时刷新页面** | 可避免样式与文字不同步问题                                       |
| 🔄 **结合 Zustand / Redux**   | 全局同步当前语言                                                 |
| 🧩 **组件级命名空间**         | 每个模块独立 JSON 文件                                           |
| 💬 **提取 key 自动化**        | 使用 [i18next-parser](https://github.com/i18next/i18next-parser) |

## 🔮 八、常见问题总结

| 问题           | 原因                                                  | 解决方案                         |
| -------------- | ----------------------------------------------------- | -------------------------------- |
| 翻译不显示     | 未引入 `import './i18n'`                              | 在入口文件中引入                 |
| 切换语言不更新 | 组件未重新渲染                                        | 确保使用 `useTranslation()` hook |
| JSON 过大      | 合并命名空间或懒加载                                  |                                  |
| SSR 语言不同步 | 使用 `next-i18next` 提供的 `serverSideTranslations()` |                                  |
