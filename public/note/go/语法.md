# 基本语法

当然可以 👍
Go（又称 **Golang**）是一门由 Google 开发的静态强类型、编译型、并发友好的编程语言。它语法简洁、性能高效，非常适合构建网络服务、分布式系统、工具程序等。

下面我将系统性地讲解 **Go 语言的语法结构**，分章节介绍，每一节都有示例代码。

---

## 🧱 一、基础结构

### 1.1 文件与包结构

每个 Go 源文件必须以 `package` 声明开头：

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

- `package main` 表示这是一个可独立执行的程序。
- 其他包（库）会使用如 `package utils`。
- `import` 用来导入标准库或自定义包。
- 程序入口函数是 `func main()`。

---

## ✍️ 二、变量与常量

### 2.1 变量声明

Go 是强类型语言，变量类型必须明确：

```go
var a int = 10
var b string = "hello"
```

也可以让编译器自动推断类型：

```go
var c = 3.14
```

简写形式（只能用于函数内部）：

```go
d := true
```

多个变量：

```go
var x, y, z = 1, 2, "go"
```

---

### 2.2 常量

使用 `const` 声明：

```go
const Pi = 3.14159
const (
    A = 1
    B = 2
    C = 3
)
```

常量值必须在编译期可确定。

## 🔄 五、控制结构

Go 没有 `while` 和 `do`，所有循环都是 `for`。

### 5.1 if 语句

```go
if x > 0 {
    fmt.Println("positive")
} else if x == 0 {
    fmt.Println("zero")
} else {
    fmt.Println("negative")
}
```

**支持初始化语句：**

```go
if n := len(name); n > 5 {
    fmt.Println("too long")
}
```

---

### 5.2 for 循环

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

类似 while：

```go
i := 0
for i < 5 {
    fmt.Println(i)
    i++
}
```

无限循环：

```go
for {
    fmt.Println("looping")
}
```

---

### 5.3 switch

Go 的 switch 不需要 `break`：

```go
switch day := 3; day {
case 1:
    fmt.Println("Mon")
case 2, 3, 4:
    fmt.Println("Midweek")
default:
    fmt.Println("Other")
}
```

也支持 `switch true`：

```go
switch {
case x > 10:
    fmt.Println("big")
case x > 5:
    fmt.Println("medium")
default:
    fmt.Println("small")
}
```

## 📦 六、函数

函数使用 `func` 定义：

```go
func add(a int, b int) int {
    return a + b
}
```

相同类型的参数可以合并：

```go
func add(a, b int) int
```

多返回值：

```go
func divide(a, b int) (int, int) {
    return a / b, a % b
}
```

命名返回值：

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return // 可省略参数
}
```

函数是一等公民，可赋值或传参：

```go
f := add
fmt.Println(f(1, 2))
```

```go

```

## 🔁 十三、并发：goroutine 和 channel

### 13.1 goroutine

```go
go fmt.Println("Hello from goroutine")
```

每个 `go` 调用会开启一个轻量级线程。

### 13.2 channel

通道用于 goroutine 之间通信：

```go
ch := make(chan int)

go func() {
    ch <- 42
}()

x := <-ch
fmt.Println(x)
```

带缓冲：

```go
ch := make(chan string, 2)
ch <- "a"
ch <- "b"
```

`select` 同时监听多个通道：

```go
select {
case msg := <-ch1:
    fmt.Println(msg)
case msg := <-ch2:
    fmt.Println(msg)
default:
    fmt.Println("no message")
}
```

## 🧹 十四、defer / panic / recover

```go
func test() {
    defer fmt.Println("deferred") // 在函数结束时执行
    fmt.Println("running")
}
```

异常处理：

```go
func risky() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recovered:", r)
        }
    }()
    panic("something went wrong")
}
```

## 📚 十七、示例：综合程序

```go

    "fmt"
)

    ID   int
    Name string
}

    fmt.Printf("Job %d: %s running\n", j.ID, j.Name)

    }

}
```

# 数据类型

下面我从 **类型分类、定义方式、转换、底层特性** 等方面系统介绍 👇

---

## 🧩 一、Go 的类型大类

Go 语言的类型主要可以分为以下几类：

| 类型类别                        | 示例                                                    | 说明                   |
| ------------------------------- | ------------------------------------------------------- | ---------------------- |
| **基础类型（Basic Types）**     | `int`, `float64`, `bool`, `string`                      | 最常见的基本数据类型   |
| **复合类型（Composite Types）** | `array`, `slice`, `map`, `struct`, `pointer`, `channel` | 由多个基础类型组合而成 |
| **函数类型（Function Type）**   | `func(int) string`                                      | 可以作为参数或返回值   |
| **接口类型（Interface Type）**  | `interface{}`                                           | 定义方法集合           |
| **自定义类型（Custom Type）**   | `type MyInt int`                                        | 基于已有类型定义新类型 |

## 🧠 二、基础类型详解

### 1️⃣ 数值类型（Numeric Types）

| 类型                                                 | 说明                                    |
| ---------------------------------------------------- | --------------------------------------- |
| `int`, `int8`, `int16`, `int32`, `int64`             | 有符号整数                              |
| `uint`, `uint8`(=byte), `uint16`, `uint32`, `uint64` | 无符号整数                              |
| `float32`, `float64`                                 | 浮点数                                  |
| `complex64`, `complex128`                            | 复数                                    |
| `rune`                                               | 表示一个 Unicode 字符（本质是 `int32`） |

示例：

```go
var a int = 10
var b float64 = 3.14
var c complex128 = 2 + 3i
```

---

### 2️⃣ 布尔类型（bool）

```go
var ok bool = true
if ok {
    fmt.Println("OK!")
}
```

---

### 3️⃣ 字符串类型（string）

字符串是 **不可变** 的 UTF-8 字节序列：

```go
s := "Hello, 世界"
fmt.Println(len(s))          // 字节长度
fmt.Println([]rune(s))       // 转为字符切片
fmt.Println(s[0:5])          // 子串（按字节截取）
```

---

## 🧱 三、复合类型（Composite Types）

### 1️⃣ 数组（array）

数组是**固定长度**的同类型元素集合：

```go
var a [3]int = [3]int{1, 2, 3}
b := [...]string{"Go", "Rust", "Python"} // 自动推断长度
```

---

### 2️⃣ 切片（slice）

切片是数组的**动态视图**，长度可变：

```go
nums := []int{1, 2, 3}
nums = append(nums, 4)
fmt.Println(nums, len(nums), cap(nums))
```

---

### 3️⃣ 映射（map）

键值对集合：

```go
ages := map[string]int{
    "Alice": 25,
    "Bob":   30,
}
fmt.Println(ages["Alice"])
```

---

### 4️⃣ 结构体（struct）

自定义复合类型，用于聚合数据：

```go
type Person struct {
    Name string
    Age  int
}

p := Person{Name: "Alice", Age: 20}
fmt.Println(p.Name)
```

---

### 5️⃣ 指针（pointer）

Go 的指针**不支持指针运算**，但可安全使用：

```go
x := 10
p := &x
fmt.Println(*p) // 10
*p = 20
fmt.Println(x)  // 20
```

---

### 6️⃣ 通道（channel）

用于 goroutine 之间通信：

```go
ch := make(chan int)
go func() {
    ch <- 42
}()
fmt.Println(<-ch) // 接收数据
```

---

## 🧩 四、函数类型（Function Type）

函数本身是一种类型，可以作为变量、参数或返回值：

```go
func add(a, b int) int {
    return a + b
}

var f func(int, int) int = add
fmt.Println(f(1, 2)) // 3
```

---

## 🧩 五、接口类型（Interface Type）

接口是一组方法的集合：

```go
type Speaker interface {
    Speak() string
}

type Dog struct{}

func (Dog) Speak() string { return "Woof!" }

func makeSpeak(s Speaker) {
    fmt.Println(s.Speak())
}

makeSpeak(Dog{}) // Woof!
```

---

## 🧩 六、自定义类型（Custom Type）

Go 允许基于已有类型定义新的类型：

```go
type MyInt int

func (m MyInt) Double() MyInt {
    return m * 2
}

var n MyInt = 5
fmt.Println(n.Double()) // 10
```

与原始类型不同，新类型不会自动转换。

---

## 🔄 七、类型转换（Type Conversion）

Go 不支持隐式类型转换，必须**显式转换**：

```go
var a int = 10
var b float64 = float64(a)
var c int64 = int64(b)
```

---

## 💬 八、空接口（interface{}）

`interface{}` 可以容纳任意类型（类似 “any”）：

```go
var x interface{}
x = "Hello"
x = 123
fmt.Println(x)
```

可以使用类型断言取出原始值：

```go
if v, ok := x.(int); ok {
    fmt.Println("是整数:", v)
}
```

---

## 🧭 九、类型别名（Type Alias）

类型别名使用 `type A = B`，与 `type A B` 不同：

```go
type MyInt = int // 类型别名，不是新类型
```

区别：

- `type MyInt int` → 定义一个**新类型**
- `type MyInt = int` → 定义一个**别名**，等价于原类型

| 函数类型   | `func(a int) int`                                       | 一等公民，可传递       |

# 结构体标签

Go 的 **结构体标签（Struct Tag）** 是一种非常实用的机制，用来在结构体字段上**附加元数据（metadata）**。这些元数据不会影响程序逻辑，但可以被 **反射（reflect）** 读取，从而在如 **JSON 序列化、数据库映射、表单绑定** 等场景中使用。

下面我帮你系统讲解一下 👇

---

## 🧩 一、结构体标签的语法

标签是一个**字符串**，放在字段声明的最后，用 **反引号 `` `...` ``** 包裹：

```go
type User struct {
    ID   int    `json:"id" db:"user_id" form:"id"`
    Name string `json:"name,omitempty" db:"user_name"`
}
```

这里的：

- `json:"id"` 是 JSON 序列化时使用的键名；
- `db:"user_id"` 可能被数据库 ORM（如 GORM）使用；
- `form:"id"` 通常用于表单参数绑定；
- `omitempty` 表示字段为空时不输出。

---

## 🧠 二、常见用途

### 1️⃣ JSON 序列化/反序列化

```go
import "encoding/json"

type Person struct {
    Name string `json:"name"`
    Age  int    `json:"age,omitempty"`
}

func main() {
    p := Person{Name: "Alice"}
    data, _ := json.Marshal(p)
    fmt.Println(string(data)) // {"name":"Alice"}
}
```

解释：

- `json:"name"`：字段在 JSON 中显示为 `"name"`。
- `omitempty`：如果字段是空值或零值，就不会出现在输出中。

---

### 2️⃣ 数据库字段映射（以 GORM 为例）

```go
type User struct {
    ID   uint   `gorm:"primaryKey;column:user_id"`
    Name string `gorm:"size:100;not null"`
}
```

作用：

- `primaryKey` 表示主键；
- `column:user_id` 指定数据库列名；
- `size:100` 表示 varchar(100)。

---

### 3️⃣ 表单字段绑定（如 Gin）

```go
type LoginForm struct {
    Username string `form:"username" json:"username" binding:"required"`
    Password string `form:"password" json:"password" binding:"required"`
}
```

说明：

- `form:"username"` 表示从表单中绑定该字段；
- `binding:"required"` 表示必填字段；
- Gin 会自动读取这些标签并验证。

---

## 🔍 三、通过反射读取结构体标签

Go 提供了 `reflect` 包用于读取标签：

```go
import (
    "fmt"
    "reflect"
)

type User struct {
    Name string `json:"name" db:"user_name"`
}

func main() {
    t := reflect.TypeOf(User{})
    field, _ := t.FieldByName("Name")

    fmt.Println("JSON 标签:", field.Tag.Get("json")) // name
    fmt.Println("DB 标签:", field.Tag.Get("db"))     // user_name
}
```

---

## ⚠️ 四、注意事项

1. **标签必须使用反引号**

   ```go
   // ✅ 正确
   Field string `json:"field"`
   // ❌ 错误
   Field string "json:field"
   ```

2. **同一字段可以有多个标签**（空格分隔）

   ```go
   Field string `json:"name" db:"user_name"`
   ```

3. **Tag 值本质上是字符串**，Go 本身不会解析或验证它们的内容。

4. **Tag 只能在编译期定义，运行时无法修改。**

---

## 💡 五、总结

| 用途        | 示例                        | 包                      |
| ----------- | --------------------------- | ----------------------- |
| JSON 序列化 | `json:"name,omitempty"`     | encoding/json           |
| 表单绑定    | `form:"username"`           | gin / echo              |
| 数据库映射  | `gorm:"column:user_id"`     | gorm                    |
| 校验规则    | `validate:"required,email"` | go-playground/validator |
| YAML 配置   | `yaml:"server_port"`        | gopkg.in/yaml.v3        |

# 格式化占位符

非常棒 👍
你问的 **“格式化占位符”** 是 Go 语言中 `fmt` 包最常用也最实用的功能之一。
它决定了 `fmt.Printf()`、`fmt.Sprintf()`、`fmt.Fprintf()` 等函数如何**格式化输出内容**。

下面给你系统、实用地讲一遍 👇

---

## 🧩 一、格式化占位符是什么

在 Go 中，`fmt` 系列函数支持使用 **占位符（verb）** 来控制输出格式。
占位符由 `%` 开头，用来指示如何将变量的值打印成字符串。

示例：

```go
fmt.Printf("名字：%s，年龄：%d\n", "Alice", 23)
```

输出：

```
名字：Alice，年龄：23
```

---

## 🧠 二、常用占位符速查表

### 🔹 基础类型

| 占位符 | 说明                   | 示例输出                          |
| ------ | ---------------------- | --------------------------------- |
| `%v`   | 变量的默认格式         | `10` / `true` / `[1 2 3]`         |
| `%+v`  | 打印结构体时包含字段名 | `{Name:Alice Age:23}`             |
| `%#v`  | Go 语法格式（含类型）  | `main.User{Name:"Alice", Age:23}` |
| `%T`   | 变量的类型             | `int`, `[]string`                 |
| `%%`   | 字面百分号 `%`         | `%`                               |

| `%x`   | 十六进制（小写） | `2a`                     |

# 多线程

在 Go（Golang）中，**多线程**的核心思想是通过 **goroutine** 和 **channel** 实现高并发与并行，而不是像 C/C++/Java 那样直接操作线程对象。
下面分层次讲清楚 Go 的多线程模型与常见用法 👇

---

## 🧠 一、Go 的并发模型：Goroutine ≠ Thread

Go 使用一种称为 **goroutine** 的轻量级线程，运行在 Go runtime 的调度器上。

### ✅ 区别

| 特性     | Goroutine             | OS Thread            |
| -------- | --------------------- | -------------------- |
| 启动开销 | 几 KB                 | 几 MB                |
| 调度者   | Go runtime (M:N 调度) | 操作系统内核         |
| 数量限制 | 可达上百万个          | 一般几千个就吃满资源 |
| 切换代价 | 极低（用户态）        | 高（内核态）         |

> **M:N 模型**：Go runtime 将 N 个 goroutine 映射到 M 个系统线程上动态调度。

---

## ⚙️ 二、启动 Goroutine

```go
package main

import (
    "fmt"
    "time"
)

func task(name string) {
    for i := 0; i < 5; i++ {
        fmt.Println(name, ":", i)
        time.Sleep(time.Millisecond * 200)
    }
}

func main() {
    go task("A") // 启动 goroutine
    go task("B") // 启动另一个 goroutine

    time.Sleep(time.Second * 2) // 主协程等待
}
```

输出是交叉的，说明两个 goroutine 并发执行。

---

## 📮 三、通信机制：Channel（管道）

Go 鼓励使用 **channel** 进行通信，而不是共享内存。

```go
package main

import "fmt"

func worker(ch chan int) {
    for n := range ch {
        fmt.Println("处理任务:", n)
    }
}

func main() {
    ch := make(chan int)

    go worker(ch)

    for i := 0; i < 5; i++ {
        ch <- i // 发送数据
    }
    close(ch)
}
```

> channel 提供了安全的同步机制，避免传统多线程锁竞争。

---

## 🧩 四、WaitGroup 等待所有 Goroutine 完成

标准库 `sync.WaitGroup` 常用于等待并发任务结束。

```go
package main

import (
    "fmt"
    "sync"
)

func main() {
    var wg sync.WaitGroup

    for i := 0; i < 3; i++ {
        wg.Add(1)
        go func(id int) {
            defer wg.Done()
            fmt.Println("Goroutine", id)
        }(i)
    }

    wg.Wait() // 阻塞直到所有 goroutine 完成
    fmt.Println("全部完成！")
}
```

---

## 🧱 五、并发安全工具

Go 标准库提供多种同步机制：

| 工具           | 作用                             |
| -------------- | -------------------------------- |
| `sync.Mutex`   | 互斥锁                           |
| `sync.RWMutex` | 读写锁                           |
| `sync.Once`    | 确保只执行一次                   |
| `sync.Cond`    | 条件变量                         |
| `sync.Map`     | 并发安全 map                     |
| `atomic`       | 原子操作（无锁计数器、标志位等） |

例：使用 `sync.Mutex`：

```go
var mu sync.Mutex
counter := 0

go func() {
    mu.Lock()
    counter++
    mu.Unlock()
}()
```

---

## 🧮 六、并行执行

Goroutine 是并发（Concurrency）结构，但 Go 也能真正**并行执行（Parallelism）**：

```go
import "runtime"

func main() {
    runtime.GOMAXPROCS(4) // 设置可用CPU核心数
}
```

Go runtime 会在多个核心上分发 goroutine，实现真正的多核并行。

---

## 🧠 七、典型应用场景

1. **并发下载/请求：**

   ```go
   go fetchURL(url)
   ```

2. **任务池/工作池：**
   使用 channel 分发任务 + WaitGroup 等待结果。
3. **并行计算：**
   将数组拆成片段并发处理，最后汇总结果。
4. **流式处理：**
   goroutine + channel 构成数据流水线（pipeline）。

---

## 🚀 八、总结

| 概念          | 对应                               |
| ------------- | ---------------------------------- |
| 并发          | 同时处理多个任务（不一定同时执行） |
| 并行          | 在多个 CPU 核心上真正同时执行      |
| goroutine     | 轻量级线程                         |
| channel       | 线程间通信                         |
| sync / atomic | 安全同步机制                       |

# 并发实践

非常好的问题 👏

这两个语句：

```go
semaphore <- struct{}{}
defer func() { <-semaphore }()
```

是 **Go 中用信号量（semaphore channel）限制并发数量** 的经典写法。
我们逐行解释一下它们的作用 👇

---

## 🧩 一、背景：为什么要用 semaphore

当你用 `go func() { ... }()` 启动很多 goroutine 时，可能会开出几千上万个协程，
如果这些协程都去调用外部 API（比如你的 `CallModel`），会导致：

- CPU 占用爆炸
- 内存暴涨
- 或者 API 并发限流（被封禁）

所以要限制同时运行的最大 goroutine 数，比如一次只跑 10 个。

这就用 **有缓冲的 channel 充当信号量（semaphore）**。

---

## 🧩 二、信号量基本原理

```go
semaphore := make(chan struct{}, 10)
```

这里的 `10` 就表示最大并发数。

---

## 🧩 三、执行关键逻辑

### ① `semaphore <- struct{}{}`

当某个 goroutine 执行到这一行时：

- 它尝试“占一个名额”
- 如果信号量没满，就成功执行；
- 如果信号量已满（比如 10 个都占用了），它就会阻塞等待。

```go
semaphore <- struct{}{} // 占一个并发名额
```

`struct{}{}` 是个 **空结构体**，不占内存，常用于这种占位信号。

---

### ② `defer func() { <-semaphore }()`

当该 goroutine 任务结束时：

- 它会执行 `<-semaphore`
- 表示释放一个并发名额（让别人可以进来）

```go
defer func() { <-semaphore }()
```

`defer` 保证即使函数提前 `return` 或出现 `panic`，也会释放信号量，避免“死锁”或“卡死”。

---

## 🧩 四、完整示例

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	semaphore := make(chan struct{}, 3) // 最多同时执行3个任务

	for i := 0; i < 10; i++ {
		go func(id int) {
			semaphore <- struct{}{}          // 占用一个并发槽
			defer func() { <-semaphore }()   // 任务结束后释放
			fmt.Printf("开始任务 %d\n", id)
			time.Sleep(2 * time.Second)
			fmt.Printf("结束任务 %d\n", id)
		}(i)
	}

	time.Sleep(8 * time.Second)
}
```

输出效果中，你会看到：

> 一次最多只运行 3 个任务。

---

## ✅ 总结

| 语句                                  | 含义                                                |
| ------------------------------------- | --------------------------------------------------- |
| `semaphore := make(chan struct{}, N)` | 创建一个最大并发数为 N 的信号量                     |
| `semaphore <- struct{}{}`             | 占一个并发名额；如果满了就等待                      |
| `defer func() { <-semaphore }()`      | 任务结束后释放名额，确保不会泄漏                    |
| 使用场景                              | 控制 goroutine 并发上限（尤其是网络请求、I/O 操作） |

# slice 库

Go 在标准库中对 **slice（切片）** 的支持比较“轻量”，它不像 Python 的 list 或 JavaScript 的 array 那样有丰富的方法（例如 map、filter、reduce），但从 **Go 1.21 开始**，官方引入了一个非常有用的泛型库：

👉 **`slices` 包**（位于标准库 `golang.org/x/exp/slices`，现在已经正式进入 Go 标准库 `slices`）。

---

### ✅ 一、`slices` 包简介（Go 1.21+ 标准库内置）

导入方式：

```go
import "slices"
```

---

### ✅ 二、常用函数示例

#### 1. **复制与比较**

```go
a := []int{1, 2, 3}
b := []int{1, 2, 3}

fmt.Println(slices.Equal(a, b)) // true
fmt.Println(slices.Clone(a))    // 返回 [1 2 3]
```

---

#### 2. **排序**

```go
nums := []int{5, 2, 8, 1}
slices.Sort(nums)
fmt.Println(nums) // [1 2 5 8]

slices.SortFunc(nums, func(a, b int) int {
    return b - a // 自定义排序规则（降序）
})
fmt.Println(nums) // [8 5 2 1]
```

---

#### 3. **查找**

```go
nums := []int{10, 20, 30, 40}

fmt.Println(slices.Index(nums, 30))   // 2
fmt.Println(slices.Contains(nums, 50)) // false

// 查找满足条件的元素
idx := slices.IndexFunc(nums, func(n int) bool { return n > 25 })
fmt.Println(idx) // 2
```

---

#### 4. **插入、删除**

```go
nums := []int{1, 2, 3, 4, 5}

// 删除下标 2 的元素
nums = slices.Delete(nums, 2, 3)
fmt.Println(nums) // [1 2 4 5]

// 插入元素
nums = slices.Insert(nums, 1, 9, 9)
fmt.Println(nums) // [1 9 9 2 4 5]
```

---

#### 5. **反转与截取**

```go
nums := []int{1, 2, 3, 4}
slices.Reverse(nums)
fmt.Println(nums) // [4 3 2 1]
```

---

#### 6. **去重（通过组合使用）**

```go
nums := []int{1, 2, 2, 3, 3, 3}
slices.Sort(nums)
nums = slices.Compact(nums) // 去掉相邻重复项
fmt.Println(nums) // [1 2 3]
```

```bash
go get golang.org/x/exp/slices
```

```go

```

API 完全一致。
