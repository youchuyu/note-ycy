# 数据库

## 🧩 一、关系型数据库（SQL）

| 数据库              | 特点                                            | 使用场景                                     | Go 生态支持                        |
| ------------------- | ----------------------------------------------- | -------------------------------------------- | ---------------------------------- |
| **MySQL / MariaDB** | 最主流，开源免费，支持事务、索引丰富            | Web 系统、微服务、大多数通用场景             | ✅ GORM, sqlx, go-sql-driver/mysql |
| **PostgreSQL**      | 功能强大，ACID 更严格，支持 JSON、GIS、全文搜索 | 对数据一致性要求高的系统，复杂查询，数据分析 | ✅ GORM, pgx, ent, sqlc            |
| **SQLite**          | 嵌入式，文件级数据库，部署极简                  | 移动端、IoT、小项目、本地开发                | ✅ GORM, mattn/go-sqlite3          |

**🔥 推荐：**

- 中小型系统 → **MySQL**
- 对事务、复杂查询要求高 → **PostgreSQL**

---

## 🗃️ 二、非关系型数据库（NoSQL）

| 数据库              | 特点                                 | 使用场景                         | Go 生态支持                    |
| ------------------- | ------------------------------------ | -------------------------------- | ------------------------------ |
| **Redis**           | 内存型，键值对，高性能缓存、队列、锁 | 缓存、分布式锁、排行榜、消息队列 | ✅ go-redis (官方推荐)         |
| **MongoDB**         | 文档型数据库，JSON-like，灵活结构    | 内容系统、日志、非结构化数据     | ✅ mongo-go-driver             |
| **Etcd**            | 分布式一致性 KV 存储，Raft 协议      | 配置中心、服务注册发现           | ✅ etcd/clientv3               |
| **Badger / BoltDB** | 纯 Go 实现的嵌入式 KV 数据库         | 本地存储、CLI 工具、嵌入式系统   | ✅ github.com/dgraph-io/badger |

**🔥 推荐：**

- 缓存层/任务分发 → **Redis**
- 文档数据/灵活结构 → **MongoDB**
- 服务发现/配置中心 → **Etcd**

---

## ☁️ 三、云数据库 & 新型数据库（现代架构）

| 数据库              | 特点                           | 使用场景                 | Go 生态支持            |
| ------------------- | ------------------------------ | ------------------------ | ---------------------- |
| **TiDB**            | MySQL 兼容的分布式数据库，HTAP | 高并发、高可用系统       | ✅ GORM, TiDB Driver   |
| **CockroachDB**     | 类似 Postgres 的分布式数据库   | 全球分布式系统，强一致性 | ✅ pgx, go-pg          |
| **ClickHouse**      | 面向列的数据库，查询快         | 日志、BI、分析系统       | ✅ clickhouse-go       |
| **InfluxDB**        | 时序数据库，适合写多读少       | 监控、IoT、时间序列分析  | ✅ influxdb/client-go  |
| **Dgraph / Nebula** | 图数据库                       | 社交图谱、推荐系统       | ✅ dgo (Dgraph Go SDK) |

**🔥 推荐：**

- 分布式 HTAP → **TiDB**
- BI/报表系统 → **ClickHouse**
- 时序监控 → **InfluxDB**

## ✅ Go 后端项目推荐组合

| 场景              | 主数据库                | 辅助组件（缓存/搜索等） |
| ----------------- | ----------------------- | ----------------------- |
| 通用 Web 应用     | MySQL / PostgreSQL      | Redis                   |
| 内容系统/文档管理 | MongoDB                 | Redis                   |
| 复杂数据统计系统  | PostgreSQL + ClickHouse | Redis                   |
| 微服务架构        | MySQL + Etcd            | Redis                   |
| IoT / 时序数据    | InfluxDB / TimescaleDB  | Redis                   |

---

## 🧠 总结建议

| 你需要什么         | 推荐                                      |
| ------------------ | ----------------------------------------- |
| 大部分系统的首选   | ✅ MySQL（成熟） 或 ✅ PostgreSQL（强大） |
| 高速缓存或任务队列 | ✅ Redis                                  |
| 动态结构、文档存储 | ✅ MongoDB                                |
| 分布式强一致性     | ✅ Etcd / TiDB                            |
| 嵌入式系统         | ✅ SQLite / Badger                        |
